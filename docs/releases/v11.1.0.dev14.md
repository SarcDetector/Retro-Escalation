# RE-OSCR 11.1.0.dev14

Dev14 is a focused independent-product-identity release and engineering checkpoint. It removes
inherited affiliation branding while preserving the OSCR parser, League authority, and Legacy
compatibility. It also publishes the source-audited plan for later CLA-compatible calculations;
those calculations do not ship in dev14.

## Independent RE-OSCR identity

- Replaced the inherited window icon, application icon, and same-size Legacy banner contents with
  original RE artwork, and added the 1024px RE master mark as the source asset.
- Removed inherited affiliation artwork, credit buttons, external affiliation links, and the
  obsolete Website row while retaining the RE-OSCR GitHub, Downloads, and AnotherNathan/CLA links.
- Rewrote About, support, credits, plaque, packaging, and release language to identify RE-OSCR as
  an independently maintained frontend using OSCR as its parser.
- Renamed the public fallback theme to `Legacy`. Its internal `default` ID, settings migration,
  layout, and behavior remain compatible.
- Updated translation catalogs, the feature poster, and the project feature, scope, testing, and
  development documents to use the independent identity.

## Analytics coprocessor groundwork — documentation only

- Added a frozen dev12 engineering baseline with exact tag, commit, release-artifact hashes,
  183-test evidence, and the parser, League, and Workbench invariants inherited by later work.
- Added a source-audited CLA v1.4.0 parity ledger covering duration and rate clocks, metric
  definitions, OSCR snapshot input limits, result provenance, tolerances, and golden-fixture work.
- Dev14 does **not** add an alternate parser, CLA calculation profile, profile selector,
  compatibility engine, or numerical-parity claim.

## Boundaries preserved

- `STO-OSCR==11.0.0` remains a separate, unmodified dependency and the single parser authority.
- Parser truth, combat selection, display-only Workbench derivation, League upload ownership, and
  the League service URLs are unchanged.
- Legacy remains functionally unchanged apart from the same-size RE banner and icon artwork.

## Verification

- All 184 regression tests pass.
- Both Legacy and Command Console construct successfully in isolated startup probes.
- Tests pin the replacement artwork hashes and dimensions and verify the removed assets, About
  links, public theme label, CLA credit, plaque wording, and Legacy banner load.
- The debranding residue gate is clean apart from the two explicitly retained functional League
  URLs, and `git diff --check` passes.
