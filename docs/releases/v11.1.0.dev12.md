Dev12 turns **05 Live Parser** into a complete Command Console control centre while keeping the
inherited OSCR parser as the single source of truth.

## Live Control Center

- One inherited live-parser session now drives the embedded preview, existing always-on-top
  popout, and optional read-only browser/OBS meter.
- Parser activity, page navigation, popout visibility, and browser visibility are independent.
  Hiding a presentation never stops parsing.
- Added a localhost browser feed with generated OBS files, a private capability URL, automatic
  reconnect, selected metrics, active palette support, and optional local CSS.
- Added explicit private-LAN support for a second streaming machine. LAN mode is unencrypted,
  binds only to the selected adapter, requires confirmation, and never auto-starts.
- Added an optional Windows global hotkey that can hide either the popout alone or the popout and
  browser meter together.
- Consolidated Live Parser graph, column, display, startup, copy, opacity, and scale controls onto
  page 05.
- Fixed direct popout closing so Command Console hides without stopping, while Legacy
  retains its inherited close-and-stop behavior.

## Distribution and verification

- Windows, Linux, and PyPI packaging now verify Qt WebSockets, bundled overlay assets, generated
  OBS files, and real localhost feed startup.
- A single version tag now publishes PyPI and creates one GitHub prerelease containing fresh
  Windows and Linux packages with checksums.
- Expanded automated coverage to 183 tests and added responsive Live-page checks at 1280x720 and
  1800x1000.

The OSCR parser, parser truth, League uploads, and Legacy services remain unchanged. The
later interactive full-console overlay is not part of dev12.

Engineering evidence for this immutable release is recorded in the
