# RE-OSCR distribution

The supported tester package is the portable Windows build documented in
[`windows/README.md`](windows/README.md).

The inherited OSCR-UI Inno, Debian, Arch, and generic PyInstaller recipes were retired when the
frontend product and Python namespace became RE-OSCR. They remain available in Git history for
reference, but they must not be used to publish RE-OSCR without being redesigned and tested under
the new application identity.

`re-oscr.desktop` is the reserved Linux desktop entry for a future tested Linux package.
